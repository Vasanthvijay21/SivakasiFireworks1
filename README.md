# Sivakasi Crackers Website

This is a premium, static, production-ready e-commerce website for Sivakasi Crackers. It requires no backend and works entirely in the browser using HTML, CSS, and Vanilla JavaScript.

## Upload to GitHub

1. Create a new GitHub repository.
2. Upload all files from this project folder into the repository.
3. Go to **Settings** > **Pages** in your GitHub repository.
4. Choose **Deploy from branch**.
5. Select **main**.
6. Select **/ (root)**.
7. Click **Save**.
8. Open the generated GitHub Pages URL after a couple of minutes to view your live website.

## How to Update Products
To update products, prices, or inventory, you do **not** need to touch the main code. 
Simply open the `products.js` file in any text editor. 

*   Locate the specific product ID.
*   Update the `actualPrice` or `discountPrice`. 
*   Save the file and upload the new `products.js` back to GitHub. The website will automatically update the interface and checkout math.
